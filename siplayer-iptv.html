What is SI Player IPTV?

SI Player IPTV (sometimes called SiPlayer) is an IPTV player application for Samsung Smart TV and LG WebOS. It supports M3U playlists and provides an interface for watching IPTV channels on Smart TVs. Note: SI Player is different from SI pTV (which has its own separate player). NorwayIPTV is compatible with SI Player via M3U URL.

SI Player vs Other Samsung IPTV Apps

SI Player competes with SET IPTV, NET IPTV, Smart IPTV and Nanomid on Samsung Tizen. All of these work with NorwayIPTV. SI Player has its own interface style — choose based on your preference after testing with the NorwayIPTV free trial.
