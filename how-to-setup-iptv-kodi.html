IPTV on Kodi — 6 Steps

1

Install Kodi

Download Kodi from kodi.tv for Windows, Mac, Android, or install from Google Play/Amazon App Store. Available free on all platforms.

2

Open Kodi → Add-ons

From Kodi home screen, go to Add-ons → search icon → type 'PVR IPTV Simple Client'. Install the add-on.

3

Configure PVR IPTV Simple Client

Open the add-on settings → General tab → M3U Playlist URL → select 'Remote Path' → paste your NorwayIPTV M3U URL.

4

Add EPG (optional but recommended)

In the same settings, go to EPG Settings → XMLTV URL → paste your NorwayIPTV XMLTV EPG URL (from your welcome email). This adds TV guide info.

5

Enable the add-on

Click OK/Save. Kodi will scan and import all channels. This takes 1–3 minutes depending on channel count.

6

Access channels in Kodi

Go to Kodi home → TV → Channels. All NorwayIPTV channels appear. Use the EPG (TV Guide) to browse what's on now and schedule recordings.

💡 Pro Tip

Enable 'Cache Mode' in PVR IPTV Simple Client settings to reduce buffering. Set cache size to 100–200 MB for smoother 4K playback on fast connections.

Kodi IPTV — FAQ

How do I install IPTV on Kodi? +
Install Kodi, then add the PVR IPTV Simple Client add-on (Add-ons → Search). Configure it with your NorwayIPTV M3U URL in the add-on settings.
What version of Kodi is best for IPTV? +
Kodi 20 (Nexus) or Kodi 21 (Omega) — both fully support PVR IPTV Simple Client and NorwayIPTV M3U playlists. Always use the latest version for best stability.
Can I record IPTV in Kodi? +
Yes — with PVR IPTV Simple Client and a DVR backend (like Tvheadend), Kodi supports IPTV recording. Simple channel recording is also possible with some configurations.
How do I add EPG to Kodi IPTV? +
In PVR IPTV Simple Client settings → EPG Settings → XMLTV URL. Enter your NorwayIPTV XMLTV EPG URL from your welcome email. Kodi then shows programme guide for all channels.
Does Kodi work on Firestick for IPTV? +
Yes — install Kodi on Firestick via sideloading (Downloader app). Then add PVR IPTV Simple Client and NorwayIPTV M3U URL. Full live TV on Firestick via Kodi.
Why won't my IPTV load in Kodi? +
Check: (1) M3U URL is correct, (2) NorwayIPTV subscription is active, (3) internet is connected and fast enough, (4) re-enable PVR IPTV Simple Client in Add-ons. Most issues resolve with a Kodi restart.
