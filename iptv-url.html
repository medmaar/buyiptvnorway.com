IPTV URL Explained — Which Link Goes Where?

Players ask for an “M3U URL”, a “server URL”, a “portal” or an “EPG URL”. They're four different things. Here's what each looks like and which apps need which.

The Four Types of IPTV URL

1. M3U playlist URL — one long link that downloads your whole channel list. It usually contains your username and password, for example:
http://server.example:8080/get.php?username=USER&password=PASS&type=m3u_plus&output=ts

2. Xtream Codes server URL — just the server address, e.g. http://server.example:8080. You enter the username and password in separate fields. Apps like IPTV Smarters and TiviMate prefer this because it loads categories, VOD and EPG together.

3. Portal URL (Stalker/Ministra) — used by MAG boxes and STBEmu, e.g. http://server.example/c/. Your login is tied to a MAC address instead of a password.

4. EPG URL (XMLTV) — the programme guide, e.g. http://server.example:8080/xmltv.php?username=USER&password=PASS. Only needed if your app doesn't fetch the guide automatically.

Examples only. The addresses above are placeholders. Use the exact URLs from your NorwayIPTV welcome message.

Which URL Does Your App Need?

  1. 1
    IPTV Smarters / TiviMate / XCIPTV — Xtream Codes: server URL + username + password. M3U also works.
  2. 2
    SET IPTV / Smart IPTV / Flix IPTV / Duplex — M3U URL, uploaded on the app's website against your TV's MAC address.
  3. 3
    MAG box / STBEmu / Formuler (portal mode) — Portal URL + registered MAC address.
  4. 4

  5. 5
    Missing guide? — Paste the XMLTV EPG URL in the app's EPG settings.

IPTV URLs — Security and Good Practice

Treat your URL like a password

An M3U or EPG URL contains your username and password. Anyone with the link can use your connections. Don't paste it into public forums, “free M3U list” sites or unknown online checkers.

M3U vs M3U8

M3U is the playlist file format. M3U8 is the same format in UTF-8 encoding and is also used for HLS streams. Most players accept both — see IPTV M3U8.

Why “free IPTV links” stop working

Lists shared publicly are usually leaked credentials or unlicensed restreams. They get blocked quickly and can expose you to malware. A personal URL from your own subscription is stable and private.

Testing a URL

The quickest test is to open the M3U link in VLC (Media → Open Network Stream). If it plays there, the URL is fine and any problem is in the app's settings.

FAQ

Frequently Asked Questions

What is an IPTV URL? +

It's the address your player uses to fetch channels. It can be an M3U playlist URL, an Xtream Codes server URL, a MAG portal URL or an EPG (XMLTV) URL, depending on the app.

What's the difference between an M3U URL and an Xtream server URL? +

An M3U URL is one long link containing your credentials that downloads the whole playlist. An Xtream server URL is just the host and port; you type the username and password separately.

Which URL do I use in IPTV Smarters? +

Choose Login with Xtream Codes API and enter only the server URL (http://host:port) plus your username and password. Pasting the full M3U link into the server field causes errors.

What is a portal URL? +

A portal URL is used by MAG boxes and STBEmu. Your subscription is linked to the device's MAC address instead of a password.

Where do I find my EPG URL? +

It's in your NorwayIPTV welcome message. Most Xtream Codes apps load the guide automatically, so you only need it for M3U-based apps.

Is it safe to share my IPTV URL? +

No. The URL contains your login. Anyone with it can use your connections, so keep it private.

What URL do XCIPTV and Smart IPTV need? +

XCIPTV uses the Xtream server URL (http://host:port) with your username and password. Smart IPTV needs the full M3U playlist URL, uploaded on the developer's website.
