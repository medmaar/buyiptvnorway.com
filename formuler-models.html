Formuler has released many IPTV boxes over the years. This guide separates the current Z11 series from older Z10, Z8, Z7+, Z+, Nano and Neo models, so you know what you're buying — new or second-hand.

Current vs Legacy Formuler Boxes

Current generation — Z11 series. The Z11 Pro Max and Z11 Pro run Android 11 and ship with Formuler's MyTVOnline 3 IPTV app. According to Formuler, the Z11 Pro Max has 4 GB RAM, 32 GB storage, Wi-Fi 6 (AX 2x2), Gigabit Ethernet, AV1/H.265 4K decoding and HDR10+.

Previous generation — Z10 series (Z10 Pro, Z10 Pro Max, Z10 SE). Still capable 4K boxes but on an older Android version.

Legacy — Z8, Z8 Pro, Z7+, Z+, Z Nano, Z Neo. Older hardware and older Android versions. They still play HD IPTV, but expect fewer app updates and slower menus with large playlists.

“BT1 Edition”

Some Z11 models are sold as “BT1 Edition”, which refers to the bundled Bluetooth voice remote. The box hardware is otherwise the same model.

Choosing a Formuler — Practical Advice

Z11 Pro Max vs Z11 Pro

Both are current Android 11 boxes with MyTVOnline 3. The Pro Max has more memory and storage, which helps when you keep large playlists, use catch-up, or install extra apps like TiviMate alongside MyTVOnline. If you only watch live TV, the Z11 Pro is usually enough.

Is an old Z8 or Z7+ still worth it?

For a bedroom TV with HD channels, an old Z8 can still work. The downsides are slower menus with big channel lists, older Android (some apps no longer install), and no more feature updates. Avoid paying near-new prices for legacy boxes.

Formuler vs Firestick vs MAG

Formuler is a dedicated IPTV box with a strong built-in player and an IR remote that controls the TV well. A Firestick is cheaper and has more apps. A MAG box is a Linux set-top box that uses a portal + MAC address. All three work with NorwayIPTV.

Where to buy

Buy from an authorised Formuler reseller. Grey-import or second-hand boxes may not receive firmware updates.
